# 系统架构说明 —— AI 教育顾问 SaaS 平台

> 交付物（A级测试单 L3）：说明 RAG 链路设计、Agent Skill 架构、数据库设计、支付流程、部署方案。

## 一、总体架构

系统为「智能体运营平台」向多租户 SaaS 的扩展。整体为单体服务（FastAPI + SQLite + React 单页应用），
在原有「知识域智能体」能力之上叠加 SaaS 层：多租户、套餐订阅、支付、租户工作台与平台经营工作台。

```
浏览器(React SPA) ──HTTP/SSE──▶ FastAPI ──▶ SQLite(data/app.db, WAL)
  /s /t /c 官方三通道            ├─ /api/auth/* 手机验证码/密码认证(JWT)
  /b/<agent_slug> 租户智能体     ├─ /api/portal/* 管理工作台(知识域/本体/配置/会话)
  /portal 统一工作台             ├─ /api/tenant/* 租户(智能体/机构信息/统计)
                                 ├─ /api/billing/* 套餐/订单/支付
                                 └─ /mcp* MCP(官方三智能体)
```

## 二、RAG 链路设计

1. **摄入**：文档（.pdf/.docx/.doc/.txt）上传 → 后台异步线程解析 → 按章节切块
   （`CHUNK_SIZE`/`CHUNK_OVERLAP` 可配）→ Embedding（火山方舟）写入 `knowledge_chunks` + FTS5(trigram) + vec0 向量表。
   后台摄入使用 autocommit 连接，每条语句即时提交，不跨网络调用持写锁，不影响其他接口。
   同名重传幂等重建，索引同步刷新。
2. **召回**：query 经 LLM 结构化改写 → 三路并行（向量 KNN / FTS5 关键词 / 本体精确事实）→ RRF 融合 → rerank → top-k。
3. **生成与引用**：`answer.md` 提示词仅依据检索结果作答；结构化引用
   `{source: 《文档名》, chapter: 章节, excerpt}` 随 done 事件下发，前端以卡片渲染；库外问题答「不在知识范围内」。

## 三、Agent Skill 架构

六个基础工具 + 两个 SaaS Skill（OpenAI function-calling JSON Schema，`app/core/tools.py`）：
- `get_course_detail`（参数 `product_name`，返回 时间/地点/费用/师资/大纲 + 引用）
- `recommend_course_type`（参数 `city`、`time_preference`，返回 1-2 个班型 + 理由 + 引用）

一套工具三种暴露：① 会话循环（`app/agent/loop.py`，租户会话按智能体配置装配）② MCP server
③ REST。降级：缺参返回 `need` 追问、实体不存在返回 `available` 列表、模型异常固定文案。

## 四、数据库设计

SQLite 单文件 `server/data/app.db`。业务本体：`domains → kbs → documents → knowledge_chunks`
（FTS5/vec0 索引）+ `entities/relations/edges/rules`（规则对象化，引擎解释执行）。
SaaS 层新增：`tenants`（机构 + `service_purpose` 服务宗旨）、`tenant_agents`（每租户多智能体，
独立 `slug` 前台链接与 `config_json`）、`plans`（三档 + `features_json` 功能位 + `agent_limit`）、
`subscriptions`（套餐与状态）、`usage_monthly`（对话计数，免费版按累计 10 次）、
`payment_orders`（`out_trade_no`/渠道/状态）、`users`（超管/租户管理员，手机号+密码）、
`sms_codes`（验证码）。作用域：会话按 `agent_id` 绑定智能体，知识域按挂载列表过滤，
租户间数据隔离。

## 五、支付流程

渠道注册表 `payments.CHANNELS`：模拟支付（演示）/ 微信 Native 扫码（V2 MD5）/ 支付宝电脑网站（RSA2）。
流程：选套餐 → 创建订单（生成商户单号）→ 微信返回 `code_url` 前端扫码、支付宝返回 `pay_url` 跳转 →
前端 2s 轮询 `GET /orders/{id}/status` 或渠道异步回调（`/api/billing/callback/*`，验签后幂等置 paid）
→ 订阅升级、功能解锁。密钥经 `.env` 注入（`WECHAT_*` / `ALIPAY_*` / `JWT_SECRET` / `ALIYUN_*` 短信）。

## 六、部署方案

- **公网**：单机 nginx → uvicorn/systemd（`deploy/opc-edu.service`），HTTPS Let's Encrypt，
  `deploy/deploy.sh` 以 tar-over-ssh 同步代码并自动重启，评审 15 分钟内可运行。
- **演示数据**：`scripts/reset_demo_data.py` 一键重建（admin 超管 + demo1/2/3 三档租户，
  三份课程 PDF 摄入）；`scripts/seed_agent_prompts.py` 幂等填充智能体提示词与欢迎语。
- 环境变量：`.env.example` 覆盖 LLM/向量/短信/支付/JWT 全部关键配置项。
